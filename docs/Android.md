# Android-версия

APK: `build/android/WildInstinct.apk`. Игра поддерживает Android 7.0+ (API 24), ARM64 и ARMv7, OpenGL ES 3.0. Сохранены все 12 бойцов, 48 приёмов и 8 арен. Интернет и разрешения на личные данные не требуются.

## Управление

- Джойстик слева: ходьба, вверх — прыжок, вниз — приседание.
- Отдельная кнопка «Прыжок» — для прыжка независимо от направления движения.
- Справа: «Удар», «Дальний», «Особый», «Ульта». «Удар» можно удерживать. Ульта требует 100 энергии.
- «Блок» удерживается; поддерживаются движение и атака несколькими пальцами одновременно.
- Кнопки «Ⅱ» и «?» сверху открывают паузу и справочник.
- Системная кнопка «Назад» открывает паузу или возвращает с текущего экрана.
- При сворачивании бой останавливается и все удерживаемые касания сбрасываются.

Игра работает в горизонтальном полноэкранном режиме. Меню управляется касаниями. Режим двух игроков предназначен для внешней клавиатуры; сенсорные кнопки управляют первым бойцом. На телефоне доступны бой с компьютером и тренировка.

## Сборка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/export_android.ps1
```

Нужны Godot 4.7.2, Java 17, Android SDK с build-tools 36.1.0 и официальный шаблон `android_release.apk` той же версии движка в `.build-tools/godot`. Пути SDK и Java уже настроены в установленном Godot. Использован локально имеющийся официальный шаблон 4.7.2; он скопирован в этот проект.

APK подписывается собственным ключом проекта. Для последующих обновлений сохраняйте **всю папку `.android-signing`**: там находятся ключ и его параметры. Папка исключена из Git и из APK. Не заменяйте ключ, если нужно обновлять установленную игру с сохранением данных.

Информация о версии, архитектурах и SHA-256 — в `build/android/APK-info.txt`.

## Установка по USB

Разблокируйте телефон, включите отладку по USB и подтвердите запрос доверия компьютеру. Команда `adb devices -l` должна показывать `device`, а не `unauthorized` или `offline`.

```powershell
adb -s 55346d017d74 install -r build/android/WildInstinct.apk
adb -s 55346d017d74 shell monkey -p org.wildinstinct.fight -c android.intent.category.LAUNCHER 1
```

Идентификатор приложения: `org.wildinstinct.fight`. Установка через `-r` обновляет приложение без удаления сохранений.

## Проверки

`tests/test_touch.gd` проверяет 16 сценариев сенсорного управления и жизненного цикла Android. `tests/test_combat.gd` проверяет 188 сценариев боевой логики. APK дополнительно проверяется `apksigner` и `aapt`; минимальный API — 24, обе ARM-архитектуры включены.
